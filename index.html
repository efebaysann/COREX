01 / The idea

Not a full app. A working reason to believe.

The assignment: rebuild the first five minutes of a real, commercially successful app. COREX proves the value proposition through one complete first-run journey — not a pile of disconnected screens.

01 / PERSONAL

Build around a real goal.

Choose a goal, enter age and measurements, then set a training rhythm. Only inputs with a visible purpose belong in the flow.

02 / INTERACTIVE

Feel the value before paying.

Complete a guided core session with a working timer, movement-specific images, clear form cues, and progress feedback.

03 / HONEST

Make the decision transparent.

The paywall comes after the workout. Pricing is clear, continuing for free is possible, and the demo processes no payments.

03 / The aha moment

One real set changes everything.

A vertical slice should be convincing because something works. In COREX, the first exercise is an experience — not a fake result screen or a static mock-up.

FEATURE 01

A working workout.

Start, pause, resume or skip. Complete two timed movements and finish the first session with real progress feedback.

FEATURE 02

Guidance you can use.

Exercise-specific coaching steps and indicative core-region bars explain each move's purpose. Target percentages are illustrative, not measured activation.

FEATURE 03

An honest paywall.

Membership options appear after the value moment. Clear demo terms, no charge, and a visible path to continue for free.
